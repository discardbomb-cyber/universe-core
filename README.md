# Universe Core — библиотека NeoForge 1.21.1

Экспериментальная библиотека расширения Minecraft: адресация вселенной, пользовательские планеты, материалы, эффекты, атмосфера и streaming. Готовые модели кораблей и игровые кампании не входят в ядро. Математические структуры секций, движения и стыковки предназначены для внешних модов.

Уточненная архитектура описана в приоритетном разделе v0.6 PLAN.md. Каталоги API не являются уже готовыми адаптерами worldgen/Block/Photon.

## Сборка

Нужны Java 21 и доступ к репозиториям Gradle/NeoForge. Версии закреплены: NeoForge 21.1.251, ModDevGradle 2.0.107. Из PowerShell:

```powershell
./gradlew.bat build
./gradlew.bat runClient
./gradlew.bat runServer
./gradlew.bat runGameTestServer
```

На этой рабочей машине Java и Gradle скопированы в игнорируемый `.tooling`, поэтому можно использовать `./tools/dev.ps1 build`, `./tools/dev.ps1 runClient` и `./tools/dev.ps1 runServer`. Серверный запуск требует самостоятельного ознакомления с Minecraft EULA. Development-миры отделены от пользовательских сохранений в `run/`.

Основной и sources jar появляются в `build/libs/`. Установить основной jar на клиент и сервер Minecraft 1.21.1 с NeoForge не ниже 21.1.251. Производственный jar исключает демонстрационные измерения, экран карты, фиксированные сферы и GameTest. Команды разработки по умолчанию отключены. `verifyCoreJar` проверяет отделение этих примеров.

## Основа библиотеки

- Типизированные адреса трех галактик, версии, SHA-256 seed, ограниченный ленивый каталог и отрицательные координаты.
- Постоянный SavedData-манифест с ID и seed мира; штатные сохранения поверхностей Minecraft.
- Чистые модели корабельных секций, позы, орбиты и стыковочной пары, покрытые тестами.
- Ограниченный сетевой протокол, ядро LOD, атмосферные профили и метаданные сохранения пространственных объектов.
- Экспериментальные public API в `dev.heiko.universe.api.planet`, `.material`, `.effect`: определения и ограниченные каталоги. Регистрация настоящих блоков, новые измерения и Photon требуют отдельных адаптеров.
- В alpha.3 добавлены `.api.gravity` (вертикальное целевое поле и единицы), `.api.environment` (газовый состав/вакуум/парциальные давления) и разрешение физических профилей планеты. Host-адаптер применяет результат к игре; образец использования и статусы трех идей находятся в `IDEAS.md`.

## Development-примеры

Gradle runClient/runServer/runGameTestServer включают `universe.demo=true`. На classpath разработки доступны четыре datapack-измерения, карта на M, три статичные сферы и команды уровня прав 2:

```text
/universe status
/universe sector milky_way 0 0 0
/universe sector end 0 0 0
/universe sector nether 0 0 0
/universe visit space
/universe visit shipyards
/universe visit barren
/universe visit temperate
/universe home
```

Команда sector раскрывает только метаданные и не загружает поверхность. Visit создает небольшую площадку в пустом измерении, сохраняя существующие блоки; переход разработки не является готовой посадкой корабля. Каменистая поверхность пока использует ванильный noise и содержит ванильные декорации. Каталоги Энда/Незера не означают посещаемые галактики.

## Проверки

Тестирование выполняет разработка. `tools/test.ps1` запускает свежие JUnit, проверку ресурсов, сборку и серверный GameTest, сохраняя журналы и `status.json`. `tools/test.ps1 -Sable` дополнительно запускает изолированный native-стенд Sable 2.0.5; его зависимости впервые подготавливаются через `gradle -PsableTests=true runSableGameTestServer` с доступом к Maven. Успех требует фактически пройденных обязательных GameTest, одного нулевого кода процесса недостаточно.

Стенд и границы native save/load описаны в `docs/SABLE_TEST_SETUP.md`. Код стенда находится в `src/sableTest`, подключается только с `-PsableTests=true` и не входит в основной jar. Этот прототип не является выпущенным переносчиком кораблей с пассажирами/стыковкой. Фактические результаты и непроверенные сценарии перечислены в `docs/VALIDATION.md`.

NeoForge/datapack адаптеры пользовательских планет, datagen и отдельный пакет 5000+ реальных блоков; backend эффектов и Photon; интеграция сводок с генерацией/рендером. Тысячи записей метаданных не доказывают производительность тысяч зарегистрированных Block или одновременных эффектов. Полный объем и приемка описаны в PLAN.md, проверки первоначальной alpha — в docs/VALIDATION.md.
