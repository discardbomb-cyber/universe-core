## Независимая проверка ресурсов

Запуск из корня: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/verify-resources.ps1`.

Подтвержденный результат валидатора: **125 проверок, 0 ошибок, 11 JSON-файлов**; см. [VALIDATION.md](VALIDATION.md). Это статическая проверка, а не приемка загрузки обычного игрового мира.

Проверяется разбор всех JSON, обязательные четыре пары измерений, основные поля и высоты dimension_type, локальные ссылки типа измерения, биома и настроек генератора в известных формах. Проверка metadata сравнивает modId/version с gradle.properties, Java ID, Minecraft interval и минимальную версию NeoForge. TOML проверяется лексически для текущего простого файла: полноценный синтаксис TOML и схемы Minecraft должны проверяться загрузчиком. Ссылки `minecraft:` проверяются только по форме; наличие в ванильном реестре не подтверждается. Скрипт не запускает Gradle и не редактирует ресурсы.

## Найденные расхождения и ограничения

- `PLAN.md`: прежнее противоречие статуса исправлено; документ прямо фиксирует утверждение запуска реализации.
- `src/main/java/dev/heiko/universe/UniverseManifest.java`: проверка `generatorVersion` добавлена. Постоянные связи body → dimension и открытия карты все еще отсутствуют в этом record; полная приемка сохранений остается открытой.
- `src/main/java/dev/heiko/universe/UniverseCommands.java`: `home` не проверяет безопасность точки; `visit` проверяет пустоту двух блоков, но не полноценную пригодность посадки. Команды явно обозначены как служебные и не должны считаться безопасной игровой посадкой.

Статическая проверка не доказывает сохранность при аварийном выключении, совместимость с другими модами, сферическую поверхность или готовность заявленного v0.1. Эти пункты закрываются отдельными интеграционными сценариями.
