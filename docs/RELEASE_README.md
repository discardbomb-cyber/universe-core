# Universe Core

Экспериментальная библиотека для Minecraft 1.21.1 / NeoForge 21.1.251 / Java 21. Текущая версия: 0.1.0-alpha.5.

Ядро содержит идентификаторы и каталоги галактик/систем/планет, модели орбиты и стыковок, ограниченные LOD-модели, сохранение метаданных и opt-in адаптер гравитации ванильных мобов. Основной JAR не содержит игрового интерфейса и готовых кораблей; для обычной установки ему не нужны Sable, Create или Photon.

Проверены 106 JUnit, 125 ресурсных проверок, 19 core GameTest и 10 ограниченных native Sable GameTest. Готовые поверхности планет, полет/посадка, перенос пассажиров и стыковочных групп, Photon-облака и производительность огромных кораблей остаются открытыми задачами. Динамический клиентский стенд находится в диагностике, приемка рендера не заявлена.

Положи `universe-0.1.0-alpha.5.jar` в `mods` отдельной сборки Minecraft 1.21.1/NeoForge 21.1.251. Инструкция ручной проверки: [PLAYER_TESTING.md](docs/PLAYER_TESTING.md).

Для сборки исходников установи Java 21 и выполни `./gradlew build` (Windows: `./gradlew.bat build`). Gradle загрузит необходимые зависимости. Демо из исходников запускается через `./tools/dev.ps1 runClient`; его карту и тестовые измерения не содержит обычный JAR. Native тесты требуют отдельного профиля и дополнительных зависимостей.

Лицензия проекта пока не выбрана. Кеши, игровые миры, сырые журналы и приватные данные не входят в публикуемый пакет.
